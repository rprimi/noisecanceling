# noisecanceling: Correcting Questionnaires for Acquiescence Response Bias

Tools for measuring and correcting acquiescence response bias (the
tendency to agree with items regardless of their content) in
psychological questionnaires built with balanced scales. Balanced scales
pair positively keyed (PK) and negatively keyed (NK) items so that a
per-person acquiescence index can be estimated and removed by centering
item responses. The approach works like noise-cancelling headphones: the
trait is the signal, acquiescence is the noise, and inverting the
negatively keyed items aligns the signal so that the noise cancels out.
The package implements the classical centering correction together with
helpers for scoring, classical psychometric analysis, and reporting.
