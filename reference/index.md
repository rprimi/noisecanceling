# Package index

## Acquiescence correction

Estimate the acquiescence index and analyse corrected scores.

- [`recode_for_acq()`](https://rprimi.github.io/noisecanceling/reference/recode_for_acq.md)
  : Recode a data frame and compute the acquiescence index
- [`find_psychometrics()`](https://rprimi.github.io/noisecanceling/reference/find_psychometrics.md)
  : Compute classical psychometrics for original and
  acquiescence-recoded scores

## Scoring

Score scales from an item dictionary.

- [`score_tests()`](https://rprimi.github.io/noisecanceling/reference/score_tests.md)
  : Score tests and compute classical psychometrics
- [`dic2keys()`](https://rprimi.github.io/noisecanceling/reference/dic2keys.md)
  : Build a scoring keys matrix from an item dictionary

## Visualising items

Inspect item response distributions.

- [`item_histograms()`](https://rprimi.github.io/noisecanceling/reference/item_histograms.md)
  : Plot item response distributions by scale and pole
- [`describe_likert()`](https://rprimi.github.io/noisecanceling/reference/describe_likert.md)
  : Diverging bar plot of Likert item responses
- [`boxplot_descritivo()`](https://rprimi.github.io/noisecanceling/reference/boxplot_descritivo.md)
  : Faceted boxplots of scale scores with standardized regressions

## Exporting results

Write psychometric results and loadings to Excel.

- [`save_item_psicom()`](https://rprimi.github.io/noisecanceling/reference/save_item_psicom.md)
  : Export psychometric results to an Excel workbook
- [`save_item_psicom_si()`](https://rprimi.github.io/noisecanceling/reference/save_item_psicom_si.md)
  : Export single-set psychometric results to an Excel workbook
- [`save_loadings()`](https://rprimi.github.io/noisecanceling/reference/save_loadings.md)
  : Export factor loadings to an Excel workbook
- [`write_sheet_in_excelfile()`](https://rprimi.github.io/noisecanceling/reference/write_sheet_in_excelfile.md)
  : Append a data frame as a new sheet in an Excel workbook

## Utilities

- [`cria_quartis()`](https://rprimi.github.io/noisecanceling/reference/cria_quartis.md)
  : Cut a numeric vector into quantile-based bins
- [`map_factor_levels()`](https://rprimi.github.io/noisecanceling/reference/map_factor_levels.md)
  : Map factor level codes to their labels
- [`sharedcount()`](https://rprimi.github.io/noisecanceling/reference/sharedcount.md)
  : Count pairwise complete cases between all column pairs
- [`` `%>%` ``](https://rprimi.github.io/noisecanceling/reference/pipe.md)
  : Pipe operator
